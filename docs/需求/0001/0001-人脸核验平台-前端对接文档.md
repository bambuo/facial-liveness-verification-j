## 接口与权限

Base URL 由业务后端下发，生产与测试环境分离。所有端上接口使用业务后端签发的 5 分钟短期 JWT。

| 接口       | 方法与路径                         | 鉴权 | 用途                                                 |
|------------|------------------------------------|------|------------------------------------------------------|
| 挑战       | `POST /v1/challenges`              | JWT  | 获取 challenge、动作与帧数                           |
| 动作预检   | `POST /v1/action-check`            | JWT  | 分段引导：确认单个动作是否已完成（不消费 challenge） |
| 无状态 1:1 | `POST /v1/matches`                 | JWT  | 参考图与现场帧比对                                   |
| 静默活体   | `POST /v1/liveness-checks`         | JWT  | 仅判断真人或攻击介质                                 |
| 人脸录入   | `POST /v1/enrollments`             | JWT  | 建立或更新人脸档案                                   |
| 档案 1:1   | `POST /v1/verifications`           | JWT  | 现场帧与已录入档案比对                               |
| 1:N 检索   | `POST /v1/identifications`         | JWT  | 在 gallery 内检索候选                                |
| 证件 OCR   | `POST /v1/documents`               | JWT  | 证件字段识别与规则校验                               |
| 异步查询   | `GET /v1/operations/{id}`          | JWT  | 查询长任务结果                                       |
| 档案查询   | `GET /v1/subjects/{subject_id}`    | JWT  | 查询档案状态                                         |
| 档案删除   | `DELETE /v1/subjects/{subject_id}` | JWT  | 删除档案与索引                                       |

请求约定：

| 项         | 说明                                                       |
|------------|------------------------------------------------------------|
| 鉴权头     | `Authorization: Bearer <JWT>`                              |
| 请求标识   | `X-Request-Id`，建议每次请求生成 UUID                      |
| 幂等       | 写接口建议带 `Idempotency-Key`                             |
| JSON 接口  | `Content-Type: application/json`                           |
| 上传接口   | `Content-Type: multipart/form-data`                        |
| 单帧大小   | 不超过 2MB                                                 |
| 请求总大小 | 不超过 20MB，最多 15 帧                                    |
| JWT 有效期 | 5 分钟，过期后重新向业务后端申请                           |
| 开发端点   | `/dev/token`、`/dev/face-test.html` 仅本地开发，生产不可用 |

## 字段说明

### 通用响应

| 字段         | 类型           | 说明                         |
|--------------|----------------|------------------------------|
| `code`       | number         | 0 表示成功，其他值见错误文案 |
| `message`    | string         | 可展示的提示文案             |
| `data`       | object 或 null | 业务数据                     |
| `request_id` | string         | 本次请求标识，排障时使用     |

### 数据类型

| 类型      | 说明                     |
|-----------|--------------------------|
| `string`  | 字符串                   |
| `number`  | 数字，分数保留 5 位小数  |
| `boolean` | 布尔值                   |
| `object`  | JSON 对象                |
| `array`   | 数组，元素类型按接口标注 |
| `null`    | 空值                     |

### 枚举

| 枚举              | 值                                                                        | 说明                                        |
|-------------------|---------------------------------------------------------------------------|---------------------------------------------|
| `scene`           | `kyc`、`withdraw`、`security_setting`、`large_payment`、`payment_method`  | 业务场景                                    |
| `mode`            | `match`、`liveness`、`enroll`、`verify`、`identify`、`document`           | 核验模式                                    |
| `liveness_status` | `real`、`spoof`、`fuzzy`、`detecting`、`error`                            | 活体状态                                    |
| `decision`        | `passed`、`review`、`no_match`                                            | 1:N 判定                                    |
| `document_type`   | `cn_id_front`、`cn_id_back`、`passport`                                   | 证件类型                                    |
| `ops`             | `match`、`liveness`、`enroll`、`verify`、`identify`、`document`、`delete` | JWT 允许的操作；`delete` 仅用于主体合规删除 |

### 请求通用字段

| 字段           | 类型   | 必填            | 说明                                |
|----------------|--------|-----------------|-------------------------------------|
| `challenge_id` | string | 上传类接口必填  | 挑战 ID，一次性                     |
| `scene`        | string | 是              | 必须与 JWT 中的 `scene` 一致        |
| `ref`          | string | 否              | 业务单号或操作引用，必须与 JWT 一致 |
| `device_id`    | string | 是              | 设备指纹摘要                        |
| `frames`       | file[] | 上传类接口必填  | 现场帧，数量等于 `frame_count`      |
| `reference`    | file   | `matches` 必填  | 参考图，如证件头像                  |
| `gallery`      | string | `identify` 必填 | 目标人脸库，必须属于当前租户        |

## 接口明细与示例

### 挑战接口

`POST /v1/challenges`

请求参数：

| 字段        | 类型   | 必填 | 说明              |
|-------------|--------|------|-------------------|
| `scene`     | string | 是   | 业务场景          |
| `ref`       | string | 否   | 业务引用          |
| `mode`      | string | 是   | 核验模式          |
| `gallery`   | string | 否   | `identify` 时必填 |
| `device_id` | string | 是   | 设备指纹摘要      |

请求示例：

```json
{
  "scene": "withdraw",
  "ref": "order_20261114_001",
  "mode": "verify",
  "device_id": "dev_9f2c1a7b"
}
```

响应字段：

| 字段           | 类型     | 说明                                                                                                               |
|----------------|----------|--------------------------------------------------------------------------------------------------------------------|
| `challenge_id` | string   | 一次性挑战 ID                                                                                                      |
| `actions`      | string[] | 随机主动动作序列：`straight` 打底，其余从 `turn_left`/`turn_right`/`mouth_open` 随机抽取；客户端需按序引导用户完成 |
| `frame_count`  | number   | 需要采集的帧数，6–15                                                                                               |
| `expires_at`   | string   | ISO 8601 过期时间                                                                                                  |
| `nonce`        | string   | 服务端随机串，随帧回传                                                                                             |

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "challenge_id": "ch_20261114_7f3a",
    "actions": ["straight", "turn_left", "turn_right"],
    "frame_count": 10,
    "expires_at": "2026-11-14T10:05:00Z",
    "nonce": "n_5c1e9a"
  },
  "request_id": "req_20261114_001"
}
```

### 无状态 1:1 接口

`POST /v1/matches`

请求参数：

| 字段           | 类型   | 必填 | 说明                           |
|----------------|--------|------|--------------------------------|
| `challenge_id` | string | 是   | 挑战 ID                        |
| `scene`        | string | 是   | 业务场景，如 `kyc`             |
| `ref`          | string | 否   | 业务引用                       |
| `device_id`    | string | 是   | 设备指纹摘要                   |
| `frames`       | file[] | 是   | 现场帧，数量等于 `frame_count` |
| `reference`    | file   | 是   | 参考图，如证件头像             |

请求示例（multipart 字段）：

```text
challenge_id: ch_20261114_7f3a
scene: kyc
ref: kyc_20261114_001
device_id: dev_9f2c1a7b
frames: face_0.jpg, face_1.jpg, ... face_9.jpg
reference: id_face.jpg
```

响应字段：

| 字段                 | 类型           | 说明                              |
|----------------------|----------------|-----------------------------------|
| `result`             | string         | `passed` 或 `failed`              |
| `score`              | number         | 1:1 相似度，0–1                   |
| `liveness`           | string         | `real`、`spoof`、`fuzzy`、`error` |
| `clarity`            | number         | 清晰度分数                        |
| `reality`            | number         | 真实度分数                        |
| `verification_token` | string 或 null | 通过时返回，供业务后端消费        |
| `request_id`         | string         | 请求标识                          |

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "result": "passed",
    "score": 0.81234,
    "liveness": "real",
    "clarity": 0.74211,
    "reality": 0.93102,
    "verification_token": "vt_eyJhbGciOi..."
  },
  "request_id": "req_20261114_002"
}
```

### 1:N 检索接口

`POST /v1/identifications`

请求参数：

| 字段           | 类型   | 必填 | 说明                           |
|----------------|--------|------|--------------------------------|
| `challenge_id` | string | 是   | 挑战 ID                        |
| `gallery`      | string | 是   | 目标人脸库，必须属于当前租户   |
| `top_k`        | number | 否   | 返回候选数，默认 5，最大 20    |
| `frames`       | file[] | 是   | 活体帧，数量等于 `frame_count` |
| `device_id`    | string | 是   | 设备指纹摘要                   |

请求示例（multipart 字段）：

```text
challenge_id: ch_20261114_a1b2
gallery: employee
top_k: 5
device_id: dev_9f2c1a7b
frames: face_0.jpg, face_1.jpg, ... face_9.jpg
```

响应字段：

| 字段                 | 类型           | 说明                                     |
|----------------------|----------------|------------------------------------------|
| `matched`            | boolean        | 是否有达到阈值的候选                     |
| `candidates`         | object[]       | 候选数组，元素含 `subject_id` 与 `score` |
| `top1_score`         | number         | 最高分                                   |
| `margin`             | number 或 null | top1 与 top2 的差值                      |
| `decision`           | string         | `passed`、`review`、`no_match`           |
| `verification_token` | string 或 null | `passed` 时返回                          |
| `request_id`         | string         | 请求标识                                 |

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "matched": true,
    "candidates": [
      { "subject_id": "user_10086", "score": 0.81234 },
      { "subject_id": "user_10010", "score": 0.42111 }
    ],
    "top1_score": 0.81234,
    "margin": 0.39123,
    "decision": "passed",
    "verification_token": "vt_eyJhbGciOi..."
  },
  "request_id": "req_20261114_006"
}
```

## 错误文案

| 错误码                    | HTTP | 建议文案                     | 前端处理                                     |
|---------------------------|------|------------------------------|----------------------------------------------|
| `AUTH_INVALID`            | 401  | 登录状态已失效，请重新进入   | 重新获取 JWT                                 |
| `TENANT_DISABLED`         | 403  | 当前业务未开通人脸核验       | 不重试，联系业务方                           |
| `QUOTA_EXCEEDED`          | 429  | 当前验证人数较多，请稍后再试 | 退避后重试                                   |
| `CHALLENGE_EXPIRED`       | 409  | 验证已超时，请重新发起       | 重新申请 challenge                           |
| `CHALLENGE_REPLAY`        | 409  | 本次验证已使用，请重新发起   | 重新申请 challenge                           |
| `NO_FACE`                 | 422  | 未检测到人脸，请正对镜头     | 重拍                                         |
| `MULTI_FACE`              | 422  | 画面中只能有一个人           | 重拍                                         |
| `LOW_QUALITY`             | 422  | 画面不清晰，请调整光线后重试 | 重拍                                         |
| `LIVENESS_FAILED`         | 422  | 活体检测未通过，请重试       | 限次重试                                     |
| `ACTION_MISMATCH`         | 422  | 动作未完成，请按屏幕提示重试 | 重试该动作（消息含实测数值，可用于联调校准） |
| `FACE_MISMATCH`           | 422  | 人脸不一致，请重试           | 限次重试或人工                               |
| `FACE_NOT_ENROLLED`       | 404  | 尚未录入人脸，请先完成认证   | 引导 enroll/KYC                              |
| `GALLERY_NOT_FOUND`       | 404  | 人脸库不存在或无权访问       | 不重试                                       |
| `IDENTIFY_REVIEW`         | 200  | 需要人工复核                 | 展示等待复核                                 |
| `DOCUMENT_UNSUPPORTED`    | 422  | 暂不支持该证件类型           | 不重试                                       |
| `DOCUMENT_LOW_CONFIDENCE` | 422  | 证件识别不清晰，请重拍       | 重拍或人工                                   |
| `DOCUMENT_INVALID`        | 422  | 证件信息校验未通过           | 不重试，提示核对                             |
| `SERVICE_UNAVAILABLE`     | 503  | 服务暂不可用，请稍后再试     | 退避后重试或降级                             |
| `DEV_DISABLED`            | 404  | 接口不存在                   | 不重试                                       |

## 注意事项

- `frame_count` 与 `actions` 以 challenge 响应为准，前端不得自行写死。
- 采集使用前置摄像头，保持单脸、正脸、光线均匀；上传前压缩到 640×480 左右、JPEG 质量 0.6–0.7。
- `challenge_id` 一次性，失败重试必须重新申请；不要复用旧 challenge。
- JWT 5 分钟有效；长流程要在过期前重新获取，不能把 JWT 缓存在本地长期使用。
- `verification_token` 必须交回业务后端消费，前端不能自行判定业务放行。
- 上传成功后删除本地临时帧；不要写入相册、AsyncStorage 或日志。
- Web 端按服务端策略降级为密码/验证码；若使用 WebView，相机权限与 HTTPS 需单独验证。
- `/dev/token` 与 `/dev/face-test.html` 仅供本地开发，生产环境必须不可用。
- 错误文案可本地化，但错误码与判定语义不得改变。
