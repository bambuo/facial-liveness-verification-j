## 目录约定

`docs/` 固定为以下五个位置，本文件是唯一总索引：

| 位置            | 约定                                                                  |
|-----------------|-----------------------------------------------------------------------|
| `README.md`     | 总索引、命名与版本规则                                                |
| `架构全景图.md` | 系统上下文、部署拓扑与运行时链路                                      |
| `功能/`         | 架构、功能清单、术语与验证限制，`{两位编号}-{中文名称}.md`            |
| `流程/`         | 按功能点拆分的流程图、时序图与状态机，`{两位编号}-{中文名称}-v{N}.md` |
| `需求/`         | 需求交付归档，`{四位需求号}/{四位需求号}-{中文名称}-{文档类型}.md`    |

功能、流程、需求分别编号，互不混用。需求目录内固定放五件套与 `assets/`、`sql/`；没有对应内容时不建子目录。
