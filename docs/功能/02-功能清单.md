# 02 功能清单

> 文档编号：02
> 项目：人脸核验平台
> 状态：设计稿，待评审
> 证据基线：技术栈切换评审（2026-11-14，Spring Boot + mica-ai-face），尚无实现代码

## 1. 统计口径

- 统计对象：`/v1` 与 `/dev` HTTP 路由、Worker 任务、客户端组件。
- 复算来源：`docs/需求/0001/0001-人脸核验平台-实施方案.md` 的接口契约与改动清单。
- 状态定义：`规划` 表示仅有设计契约；`已实现` 表示代码与测试已落地；`已停用` 表示入口保留但不再使用。
- 当前基线（2026-11-14 复算）：HTTP 路由 15 个（`/v1` 13 个、`/dev` 2 个），Worker 任务 4 个，客户端组件 2 个。技术栈由 .NET 切换为
  Spring Boot + mica-ai-face 后，原 .NET 实现不再作为依据，dev H5 与 5
  条路由（/dev/token、/v1/challenges、/v1/action-check、/v1/enrollments、/v1/verifications）已实现并通过 curl +
  浏览器真人冒烟；其余路由/任务仍为 `规划`。
- 每次实现变更必须改从路由注册（`face-service-api` 模块 `faceservice.api` 包下 `*Controller`）、Worker 注册（
  `faceservice.worker` 包下定时与队列任务）和组件导出复算，不能沿用本文数字。

## 2. HTTP 路由

| 模块 | 方法与路径                         | 鉴权       | 功能                                                           | 状态   | 备注                                     |
|------|------------------------------------|------------|----------------------------------------------------------------|--------|------------------------------------------|
| 会话 | `POST /v1/sessions`                | 服务间签名 | 平台签发短期端上 token                                         | 规划   | 业务后端也可自行签发 JWT                 |
| 挑战 | `POST /v1/challenges`              | 短期 JWT   | 下发随机主动动作序列（正视+转头/张嘴）、帧数、nonce 与过期时间 | 已实现 | 一次性，绑定 tenant/sub/scene/ref/device |
| 预检 | `POST /v1/action-check`            | 短期 JWT   | 单动作预检：页面分段引导时确认动作是否完成，不消费挑战         | 已实现 | 一次性，绑定 tenant/sub/scene/ref/device |
| 比对 | `POST /v1/matches`                 | 短期 JWT   | 无状态 1:1，参考图 + 现场帧                                    | 规划   | 不落库                                   |
| 活体 | `POST /v1/liveness-checks`         | 短期 JWT   | 仅静默活体                                                     | 规划   | 不比对身份                               |
| 档案 | `POST /v1/enrollments`             | 短期 JWT   | 建立或更新人脸档案                                             | 已实现 | 存加密特征                               |
| 档案 | `POST /v1/verifications`           | 短期 JWT   | 档案 1:1                                                       | 已实现 | 需先 enroll                              |
| 检索 | `POST /v1/identifications`         | 短期 JWT   | 在 gallery 内 1:N 检索                                         | 规划   | 返回 topK、分数与 margin                 |
| 证件 | `POST /v1/documents`               | 短期 JWT   | 证件 OCR、字段校验、可选人证 1:1                               | 规划   | 按租户模板                               |
| 异步 | `GET /v1/operations/{id}`          | 短期 JWT   | 查询异步任务结果                                               | 规划   | 同步接口不经过此路由                     |
| 主体 | `GET /v1/subjects/{subject_id}`    | 短期 JWT   | 查询档案与状态                                                 | 规划   | 仅返回状态，不返回特征                   |
| 主体 | `DELETE /v1/subjects/{subject_id}` | 短期 JWT   | 合规删除档案、特征与索引                                       | 规划   | 需审计                                   |
| 结果 | `POST /v1/results/{jti}/consume`   | 服务间签名 | 原子消费结果令牌 jti                                           | 规划   | 配合 verification_token 使用             |
| 开发 | `POST /dev/token`                  | 无         | 本地签发 dev JWT                                               | 已实现 | 仅 Development 且 `EnableDevToken=true`  |
| 开发 | `GET /dev/face-test.html`          | 无         | 本地 H5 采集页                                                 | 已实现 | 仅 Development，不进入生产发布           |

## 3. Worker 任务

| 任务            | 触发方式  | 功能                                           | 状态 |
|-----------------|-----------|------------------------------------------------|------|
| 异步任务执行    | 队列      | 执行 OCR、1:N 等异步请求并回写 face_operations | 规划 |
| 会话与 jti 清理 | 定时      | 清理过期 challenge、jti 与短期会话             | 规划 |
| 留存清理        | 定时      | 按租户策略删除原图、过期档案与审计可删字段     | 规划 |
| 索引重建        | 手动/迁移 | 模型升级后重建 pgvector 索引并回填             | 规划 |

## 5. 本期不做

| 项            | 原因                                                 |
|---------------|------------------------------------------------------|
| 跨租户 1:N    | 租户隔离与合规要求，不允许跨租户检索                 |
| 证件真伪鉴定  | 需要全息、UV、纸张纹理等专用能力，开源 OCR 不具备    |
| 人工复核后台  | 首期只提供结果与审计，复核流程由业务侧或后续需求承接 |
| 商业 SDK 接入 | 本期限定免费开源组件                                 |

## 6. 规划与实现差异

已实现项的实现位置（2026-11-14 复算）：

| 已实现项                  | 路由/入口                                                            | Application 用例                                                       | 依赖                            |
|---------------------------|----------------------------------------------------------------------|------------------------------------------------------------------------|---------------------------------|
| `POST /dev/token`         | `faceservice.api.web.DevTokenController`（dev profile + 开关双条件） | `application.token.TokenService.issueDevToken`                         | jjwt                            |

| `POST /v1/action-check`   | `faceservice.api.web.ActionCheckController`                          | `application.challenge.ActionVerifier.checkAction`（引导用，无副作用） | mica-ai-face                    |
| `POST /v1/enrollments`    | `faceservice.api.web.EnrollmentController`                           | `application.enroll.EnrollmentService`（活体投票→动作校验→加密落库）   | mica-ai-face、PG、Redis、密钥库 |
