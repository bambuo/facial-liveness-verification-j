## 1. 主术语

| 主术语     | 英文/代码映射          | 定义                                                                                       | 允许别名   | 避免用法               |
|------------|------------------------|--------------------------------------------------------------------------------------------|------------|------------------------|
| 租户       | `tenant_id`            | 调用平台的一条业务线或应用                                                                 | 业务方     | 客户、公司、商户       |
| 主体       | `subject_id`           | 租户内的核验对象，通常是业务用户 ID                                                        | 用户       | 账号、会员             |
| 会话       | `session`              | 一次 challenge 到结果的完整核验过程                                                        | 验证会话   | 订单、请求             |
| 挑战       | `challenge`            | 平台下发的动作、帧数、nonce 与过期时间                                                     | 挑战码     | 令牌、验证码           |
| 现场帧     | `probe frames`         | 本次采集的人脸图片序列                                                                     | 自拍帧     | 照片、视频             |
| 参考图     | `reference image`      | 用于 1:1 的对照图，如证件头像                                                              | 底图       | 模板、样本             |
| 特征       | `embedding`            | 人脸模型输出的定长向量                                                                     | 人脸特征   | 指纹、模板             |
| 档案       | `face_profile`         | 主体在平台内的人脸特征与状态                                                               | 人脸档案   | 账号、资料             |
| 人脸库     | `gallery`              | 1:N 检索的特征集合，按租户隔离                                                             | 检索库     | 数据库、表             |
| 1:1 比对   | `match` / `verify`     | 两张人脸或现场帧与档案的相似度判定                                                         | 比对       | 识别、认证             |
| 1:N 检索   | `identify`             | 在 gallery 内检索候选主体                                                                  | 检索、查找 | 比对、匹配             |
| 活体       | `liveness`             | 判断采集对象是真人还是攻击介质                                                             | 活体检测   | 防伪、真人检测         |
| 静默活体   | `silent liveness`      | 不要求用户做指定动作的活体检测                                                             | 被动活体   | 无感活体               |
| 主动动作   | `action`               | 要求用户完成的指定动作：`straight`/`turn_left`/`turn_right`/`mouth_open`，挑战下发随机序列 | 动作活体   | 眨眼（当前引擎不支持） |
| 动作预检   | `action-check`         | 分段引导时对单动作的实时校验，不消费挑战、不写库；最终判定以整单校验为准                   | 实时校验   | 端上判定               |
| 清晰度     | `clarity`              | 活体检测中的图像清晰度分数                                                                 | 质量分     | 亮度、分辨率           |
| 真实度     | `reality`              | 活体检测中的真人概率分数                                                                   | 活体分     | 相似度、置信度         |
| 相似度     | `similarity` / `score` | 两个人脸特征的接近程度                                                                     | 分数       | 概率、准确率           |
| 差值裕量   | `margin`               | 1:N 中 top1 与 top2 的分数差                                                               | 裕量       | 间隔、差距             |
| 阈值       | `threshold`            | 判定通过与否的配置值                                                                       | 门限       | 固定值、硬编码值       |
| 结果令牌   | `verification_token`   | 平台签名的核验结果，供业务后端验签与消费                                                   | 结果 token | JWT、会话 token        |
| 一次性标识 | `jti`                  | JWT 唯一 ID，用于防重放                                                                    | 令牌 ID    | 随机数、nonce          |
| 证件 OCR   | `document OCR`         | 识别证件字段并做规则校验                                                                   | 证件识别   | 证件审核、实名         |
| 证件模板   | `document template`    | 按证件类型定义的字段抽取规则                                                               | 模板       | 正则、脚本             |

## 2. 易混术语对照

| 容易混用             | 正确口径                                                                 |
|----------------------|--------------------------------------------------------------------------|
| 人脸认证 / 人脸核验  | 本文统一用“人脸核验”；“认证”仅指业务侧的登录或实名状态                   |
| 比对 / 识别          | 1:1 叫“比对”，1:N 叫“检索”；不要用“识别”指代两者                         |
| 活体 / 防伪          | 活体是判定真人；防伪是更广的攻击对抗，包含活体、设备、风控               |
| 静默活体 / 主动动作  | 静默活体是模型对帧的判定；主动动作是几何校验的用户配合要求，两者叠加使用 |
| 精度 / 召回 / 通过率 | 分别指模型指标、命中能力和业务通过比例，不可混用                         |
| 阈值 / 分数          | 阈值是配置的判定线，分数是本次计算的输出                                 |
| 模板 / 特征          | 模板是证件字段规则；特征是人脸 embedding                                 |
| 会话 / 挑战          | 会话覆盖整个核验过程；挑战只是其中一次动作与 nonce 的下发                |

## 3. 状态口径

| 对象 | 状态            | 含义                   |
|------|-----------------|------------------------|
| 会话 | `Created`       | 已创建，尚未下发挑战   |
| 会话 | `Challenging`   | 已下发挑战，等待采集   |
| 会话 | `Collecting`    | 正在接收帧             |
| 会话 | `Processing`    | 正在检测、活体或比对   |
| 会话 | `Passed`        | 活体与比对均通过       |
| 会话 | `Failed`        | 活体或比对失败         |
| 会话 | `Expired`       | 超过有效期或被清理     |
| 档案 | `None`          | 未录入                 |
| 档案 | `Enrolling`     | 录入处理中             |
| 档案 | `Active`        | 可正常 1:1 或参与 1:N  |
| 档案 | `Deleting`      | 删除处理中             |
| 档案 | `Deleted`       | 已删除，不可检索       |
| 证件 | `Uploaded`      | 已上传，等待 OCR       |
| 证件 | `OcrProcessing` | OCR 处理中             |
| 证件 | `OcrDone`       | OCR 完成，字段可用     |
| 证件 | `Rejected`      | 字段校验或人工复核拒绝 |

## 5. 现状问题

- 代码尚未实现，以上映射为设计命名，落地时以实际类型与表名为准。
- “人脸认证”在现有 `cpay-api` 文档中指人工审核流程，与本平台的“人脸核验”不是同一概念，跨文档引用时必须写全称。
